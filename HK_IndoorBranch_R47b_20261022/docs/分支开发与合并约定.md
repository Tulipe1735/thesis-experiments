# 分支开发与合并约定

共同基线：HK49 R47b，文件 `scene/HK_District_BASE_R47b.blend`。外围工作线在自己的新版本中继续；本包基线在交接后固定。

## 1. 各自负责什么

| 工作线 | 可编辑内容 | 回交方式 |
|---|---|---|
| 外围维护方 | 既有室外精修、城市整合版本与整体验收 | 持续保存新的完整街区 |
| 学长室内分支 | 新房间、室内设施、家具、道具、局部碰撞和桌面实验 | 新增室内集合与任务增量 |
| 合并阶段 | 门口/窗后边界、楼层连接及必要的共同界面 | 在最新完整街区的副本中检查后合入 |

既有 E01-r47、DH01-r10 以及新室内范围外的城市对象作为背景基线保留。原 DH01 房间与楼层布置含合理推断，并非实测租户竣工平面。新场景的证据与推断也应分开记录。

## 2. 坐标与定位

- 米制，右手系，X 向东、Y 向北、Z 向上。**X=E−839826；Y=N−816525；Z=HKPD**。
- 城市工作范围为 X/Y 各 −250..250m。既有上下文几何超出边界不意味着扩大施工范围。
- 不把整城归零、缩放或镜像；不要再次应用旧 Rapier 的轴变换。
- 若在完整街区副本里建室内，默认使用现有全局坐标。选择建筑后记录建筑对象名/身份、楼层、地坪 HKPD、高程依据、门口锚点、室内范围。
- 若先在原点附近搭建独立桌面实验，标记为 `local_room`，填写 **local_to_hk 的4×4矩阵**后才能进入城市合并；只应用一次变换，并核对单位、朝向和地坪。位置未确定的实验场景可以测试，但不能直接宣称已与城市对齐。
- `branch/DH01r10_legacy_coordinate_and_registration.json` 仅是既有 DH01 的历史注册，不可把其中的16.35m地坪或旋转照搬到另一栋楼。

## 3. 命名、身份与共享数据

新根集合固定为 `IN_SENIOR_20261022`，子集合建议分 `Architecture`、`Furniture`、`TaskProps`、`Colliders`、`Cameras`、`Lights`。对象名使用 `INS22__` 前缀；为可交互对象保存稳定的 `hk_merge_id` 与 `task_object_id` 自定义属性，重命名后保持ID不变。这份包未预建新房间，也没有虚构资产ID。

复制既有物体作为参考时，要复制所需的网格/材质再修改，避免共享材质变更影响室外。跨集合父子关系、约束、驱动器、几何节点或集合实例会形成隐含依赖；导出前逐项检查。不要把整个旧城市作为室内集合的父对象或实例打入增量。

如果入口需要开洞、移除旧窗后边界或改变公共连接，把目标原对象、理由、改动范围和前后证据写入 `requested_base_changes.json`，由城市维护方在合并副本中处理。新房间局部灯光放入自己的集合；世界环境、城市曝光和既有灯光单独记录为请求，不随室内增量自动替换。

## 4. 如何回交

将 `branch/BRANCH_MANIFEST.template.json` 复制到工作目录并填写，回交：

1. `interior_delta.blend`：只包含新根集合、其必要依赖及已打包素材。
2. `branch_manifest.json`：共同基线SHA、位置/高程、集合名、稳定ID、范围、资产来源与仍未完成项。
3. `requested_base_changes.json`：需要修改原场景的请求；没有则保留空列表。
4. 实际使用的建模/导出源码，以及室内正向、反向、门口接续图。
5. 若进行了桌面实验，再附任务配置、初态/复位定义、成功判据和完整试验记录。

可以新建一个空 Blender 文件，通过 **File → Append → 工作文件 → Collection → IN_SENIOR_20261022** 追加集合，检查依赖与位置，再打包外部资源并另存 `interior_delta.blend`。重新打开增量文件，确认没有缺图、丢对象或意外带入整城。原完整工作副本可自己保留，不用每次回传。

## 5. 城市维护方如何合并

在当时最新外围工程的**新副本**中 Append 室内根集合，核对 manifest 中的共同基线。若该集合名或稳定ID已存在，先比较两个室内版本，不直接重复追加。局部坐标场景应用一次已确认的 local_to_hk；全局坐标场景保持原变换。

检查门槛、地坪/顶面、室外视窗、楼层流线、材质共享、照明与碰撞。仅按已审阅的请求改动原建筑界面，再重开、渲染室内正反向与室外接续，检查范围外保持。合并验收后另存新的完整城市；保留原外围版本与室内增量，便于定位和回退局部问题。

这套分工支持后续增量合并，但不保证两个任意修改过的完整 `.blend` 可以自动无冲突合并。
