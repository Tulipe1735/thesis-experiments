# 香港室内场景任务（单房间）

## 物品获取与递送

- 指定物品取用
  - 茶水间：取起指定空杯
  - 办公室：取用指定文件盒
- 指定地点递送
  - 讨论室：将材料盒送到指定座位
  - 咖啡服务区：将杯碟送到指定取餐位
- 多物品集中取送
  - 培训室：将指定教具集中送到讲台
  - 餐厅：将各桌空杯盘集中送到回收台

## 整理、收纳与补给

- 按类别分拣
  - 办公室：按标签将文件盒归入对应柜格
  - 茶水间：将空杯与密封水瓶分类归位
- 排列、堆叠与嵌套
  - 餐厅：按席位定向摆放杯盘餐具
  - 咖啡服务区：将空杯碟在备品区叠放
- 数量补给与库存恢复
  - 茶水间：将取杯区补到指定杯数
  - 培训室：只给缺材料的座位补发材料盒
- 台面腾空与空间复位
  - 办公室：保留办公设备并清出指定工作区
  - 讨论室：收拢用品并腾出共享桌面

## 办公与会议准备

- 个人工作位准备
  - 办公室：按工位清单配齐文具与材料盒
- 多座位会议布置
  - 讨论室：按参会名单为各席位配齐用品
  - 培训室：按座位安排配齐不同课程的材料盒
- 办公材料装配与打包
  - 培训室：按课程清单将刚性教具装入材料盒
- 展示与协作用品准备
  - 讨论室：将白板笔与板擦放入对应托槽
  - 培训室：将演示教具布置到讲台指定位置

## 饮品准备与服务

- 饮用器具准备
  - 茶水间：按茶歇人数摆放空杯
  - 咖啡服务区：按订单匹配空杯与杯碟
- 饮料原料与耗材准备
  - 茶水间：按清单配齐封装茶包与茶匙
  - 咖啡服务区：将封装耗材放入对应备品格
- 成品饮品供应
  - 餐厅：按席位分发密封瓶装饮品
  - 咖啡服务区：按取餐号摆放密封饮品

## 设施、设备与环境设置

- 门、抽屉与盖体状态设置
  - 茶水间：将指定橱柜门开至目标状态
  - 办公室：将文件柜门恢复为关闭状态
  - 餐厅：将餐具抽屉推回闭合状态
- 按钮与拨杆设置
  - 讨论室：将照明开关设置为指定状态
  - 咖啡服务区：将设备控制件设置为指定状态
- 部件插接与装卸
  - 办公室：将刚性耗材匣装入对应设备槽位
  - 咖啡服务区：将可拆托盘装回指定卡槽
