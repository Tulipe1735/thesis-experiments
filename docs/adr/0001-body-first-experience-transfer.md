# 以身体熟悉为主干，以新实例上的经验迁移为主要研究目标

2026-10-24，用户明确选择“身体操作练习 -> 经验或技能积累 -> 应用任务 -> 组合任务”的研究主线，而不是先以生活用途目录为中心或只优化单个 VLA 抓杯结果。核心证据是积累经验后在新任务实例上的表现改善；已有 L0 / L1 目的分类保留为应用层，不能用现成工程抓取工具的成功替代身体练习及经验迁移的证据。

本决定不授权启动实验，也不意味着必须从零学习所有底层控制。后续对齐已由 [ADR-0002](0002-joint-exploration-and-executable-skills.md) 明确关节级试探与可执行程序技能；用户另澄清跨尺度是可能跨空间的连续动作任务，仅保留为未来设想，不纳入当前阶段。
