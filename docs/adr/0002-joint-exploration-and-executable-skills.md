# 通过关节级试探积累经验，以可执行程序承载技能

2026-10-24，用户选择让 agent 直接向各关节下指令、通过试探熟悉运动关系，而不采用上一轮推荐的现成末端 IK 求解作为主实验动作接口；skill 确定为可执行程序，memory 确定为条件与经验知识。这样保留了身体关系需要由实际练习积累的研究问题，代价是不能用已有 IK 或完整抓杯程序的能力替代试探过程；技能在执行时也须遵守同一动作边界。

后续 [ADR-0003](0003-body-knowledge-and-agent-authorship.md) 已明确完整身体说明与当前掌位反馈、先单侧臂手、agent 自主试探与生成经验 / 技能。该决定不要求从零训练大模型或底层伺服，不要求必须训练新 VLA 权重，也不授权启动实验；依据已给几何推导的运动关系与来自实际交互的经验必须分别标明来源。

[ADR-0004](0004-synthesis-improvement-and-frozen-transfer.md) 进一步明确：Agent 自主实现并调试改进的 IK / 控制程序合法；限制的是预置高级求解工具和非法信息，而非所有求解算法。
