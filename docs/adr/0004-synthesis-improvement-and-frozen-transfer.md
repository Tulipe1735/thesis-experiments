# 区分知识合成与经验改进，以冻结迁移作为 Grow Up 主实验

2026-10-24，用户明确允许 Agent 自主编写、调试和改进 IK、运动学求解器及其他控制程序：仅使用 Prompt 提供的机器人资料、获准公开 API、自身执行反馈，最终经合法关节接口执行，不调用预先封装的高级任务求解工具或读取隐藏真值。程序须先作为 Candidate Skill，经实际执行验证后才晋升为正式 Skill；知识驱动 Skill Synthesis 与经验驱动 Skill Improvement 都属于 Grow Up，但必须分别归因。

首批保持同杯型，把新杯位与新起始关节姿态分开测试；练习后冻结 Skill / Memory，再评测未见实例。Online Continual Learning 保留为后续独立实验；练习阶段对技能程序的自主调试与改进已获明确允许，之前“暂不自主修订”的笼统措辞不再限制这一局部过程，但不扩展到 agent 框架自改、评测规则自改、root down 或元探索策略递归优化。

当时具体阈值、预算和晋升协议仍待整体确认，且本决定本身不授权启动实验；后续执行事实与当前规则以最小实验方案（已归档，见 `archive/docs_prune_20261114_001.json`）为准。

## 2026-10-25 晋升规则修订

用户明确取消“20 个独立实例、P/J 各 10 个”作为首次入库的强制门槛。冻结候选现在以一个同初态配对作为最小晋升单元：一回合不开放候选 Skill，一回合开放并实际调用候选 Skill；除 Skill 条件外，物理初态、Memory、模型与 Prompt、原子工具、预算、安全限制和独立评价器保持一致。Skill 回合须通过任务验收且无权限违规或硬安全故障；在此前提下，Skill 成功而基线失败、完成前失败/重试更少，或稳定完成至少快一个评价采样间隔，任一项成立即可晋升为 `Paired-Validated Skill`。两回合都失败、Skill 失败而基线成功，或两项效率指标都没有改善则不晋升。

跨 seed、P/J 分轴与更多重复改为可选的扩展验证，用于扩大适用范围，不再阻止一个已通过配对的技能进入正式库。单个配对只能支持绑定任务、资产、依赖版本和初态条件的局部结论；若 Skill 程序、关键参数或依赖发生变化，产生新版本并重新配对。历史回合仍按执行时协议记录，不事后改写原始结果。

## 2026-10-25 修复谱系验证补充

用户进一步确认：候选的完整修复过程和最终成功程序可以共同构成正式 Skill 证据，不要求所有候选都另做有/无 Skill 两视频配对。因此增加 `repair_lineage` 正式验证等级，与 `paired` 并列。它要求完整保留原失败，使用合法观测和保存状态给出诊断，在不放宽任务谓词、独立评价器、安全门槛、数据权限和预算的前提下作有界修复；随后从同一实际初态分别由确定性脚本和 agent 调度最终程序，两者都通过独立验收。最终程序须与成功回合实际执行序列一致，并冻结程序、依赖和证据哈希。

该等级只证明记录条件下的修复链及最终程序有效，不把程序变化误写成 Skill 单因素对照，也不支持跨初态、跨资产或实体可靠性。没有完整失败修复链的下一候选仍默认采用 `paired` 两视频路径；跨 seed、P/J 仍只用于扩大适用范围。
